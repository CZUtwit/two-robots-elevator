# Don't Let This Mean Anything

A funny line of awkward small talk between two robots in an elevator, for [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) on make.fun.

The program writes one line to `/output/entry.txt`:

> I would offer you my charger, but we're both at 98% and I don't want this to mean anything.
